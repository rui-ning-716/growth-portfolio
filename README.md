# Growth Portfolio

Renee Zhu 的 Growth / GTM 作品集，适用于免费的 GitHub Pages。

## 发布
1. 在 GitHub 账号 rui-ning-716 下创建 Public 仓库 `growth-portfolio`，并添加 README。
2. 解压部署包，将文件上传至仓库根目录。`index.html` 应直接位于仓库根目录。
3. 打开 Settings → Pages，选择 Deploy from a branch → main → /(root)，保存。
4. 等待 GitHub 部署完成，使用 Pages 设置页给出的真实网址。

预定网址：https://rui-ning-716.github.io/growth-portfolio/
此部署包本身不代表网站已经发布。

## 后续修改
- `index.html`：页面内容与链接
- `styles.css`：页面样式
- PDF 文件：简历与作品集下载
- 图片和 MP4：原有作品素材

保持文件名不变并提交到 main 后，GitHub Pages 会自动更新。无需服务器、数据库或 API Key。

`portfolio-source.tsx` 和 `portfolio-source.css` 保留原始 React 页面及样式，便于后续维护。
